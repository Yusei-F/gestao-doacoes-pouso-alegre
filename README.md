Para testar o sistema localmente clone o repositório na pasta htdocs do XAMPP.
certifique-se de que o Apache e o MySQL estão ativos. Criar a pasta no seguinte caminho: "C:\xampp\htdocs\gestao-doacoes-pouso-alegre"
Para começar recomenda-se baixar o arquivo instalar.php e jogar na pasta raiz criada C:\xampp\htdocs\gestao-doacoes-pouso-alegre 
o arquivo instalar.php vai gerar instantaneamente todo os arquivos que ja estão no repositório sem alterações 
Abrir o navegador e executar o seguinte link para que o script instalar seja executado: http://localhost/gestao-doacoes-pouso-alegre/instalar.php no navegador 
Os testes podem ser feitos tanto baixando o repositório, tanto quanto executando o script instalar.
